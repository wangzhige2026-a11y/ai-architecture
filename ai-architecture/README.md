# 知筑 · AI 结构病害检测工作台

一个面向桥梁/建筑结构表面裂缝的自动化检测系统，包含规则方法（多尺度黑帽形态学）和轻量级语义分割模型（CrackNet）双引擎。

## 核心特性

- **双核黑帽检测**：小核找细缝 + 大核找粗缝，可检出 2~44px 宽的裂缝
- **CrackNet 轻量模型**：43,265 参数 / 183KB 权重，基于空洞卷积的像素级裂缝分割
- **把握度校准**：模型自报不确定性（高/中/低三档），不做假装自信的判断
- **裂缝逐条分析**：编号、严重度（重/中/轻）、宽度、长度、把握度直接标注在图上
- **Web 界面**：深色主题工作台，支持图片上传、检测结果可视化、报告导出
- **合规审查**：内置建筑规范检查模块（疏散距离、活荷载、结构稳定性等）

## 检测原理

### 规则方法（默认引擎）

1. **去噪**：双边滤波保边
2. **双核黑帽**：小核（~17px）检测细缝，大核（~51px）检测粗缝
3. **Otsu 自适应阈值**：各自二值化后合并
4. **连通域过滤**：面积/细长度筛选，阴影带/污渍标记为"疑似"
5. **逐条分析**：骨架提取 → 宽度/长度计算 → 严重度百分位排序

### CrackNet 模型

- 架构：空洞卷积（dilation=2/4/8）+ 融合层 + 1×1 输出
- 输入：256×256 灰度图
- 输出：像素级裂缝概率图
- 把握度校准：基于 100 张公开数据集的可靠性分析

## 已知边界

- 超过约 44px 的裂缝可能漏检（黑帽核物理上限）
- 宽度是**估算上界**（实际 2px 会检出约 3px）
- 把握度校准基于公开数据集，非真实现场验证
- 严重度是图内相对排序，非规范定级（需配合标尺+规范使用）
